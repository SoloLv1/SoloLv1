MY STORY
```
```

私は、
自分のことが
あまり好きじゃなかった。

1
```
```

そんな私の毎日に、
ひとりの人が
増えた。

そして私は、
少しずつ
「好き」を増やしていった。

2
```
```

好きなものが増えると、
不思議なことに
自分のことも
少しずつ見えるようになった。

3
```
```

「伝わらないなら、
言わないほうがいい。」

そう思っていた私に、

「どういうこと？」
「教えて？」

そうやって
待ってくれる人がいた。

4
```
```

伝わらなくても、
伝えていい。

時間がかかっても、
自分の言葉で話していい。

5
```
```

「これも、私じゃん。」

周りと違うところも、
不器用なところも、
ぜんぶ私。

6
```
```

もちろん、
いつも前向きではいられない。

嫉妬したり、
悩んだり、
自分を嫌いになりそうな日もある。

7
```
```

でも今は、
そんな感情があることも
含めて、

「これも私なんだ」って
少しずつ思える。

8
```
```

私は、
少しずつ変わっていく。

誰かになったんじゃない。

私が、私になっていく。

9
```
```

ここまで来た私へ。

よく頑張ったね。

これからも、
自分の物語を
自分の言葉で書いていこう。
